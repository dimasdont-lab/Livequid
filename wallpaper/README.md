# Livequid wallpaper (Windows)

Живі шпалери на всі монітори як одне полотно: тонка темно-зелена «матрична» сітка
і велика прозора гелева (liquid glass) клякса в невагомості.

- **Курсор штовхає гель.** Швидкий рух розбризкує клякса на краплі, повільний — акуратно деформує.
- **Повільний курсор збирає краплі** (як магніт); краплі, що торкнулись одна одної чи кляксі, зливаються.
- Краплі летять як у невагомості, відбиваються від країв моніторів (по об'єднанню прямокутників моніторів, тож через стик екранів гель тече вільно).
- Легкий: Python + OpenGL, гель рендериться в напіврозширенні, фізика ~0.5 мс/крок; пауза, коли відкрито повноекранну гру/відео.

## Запуск
1. Завантаж папку `wallpaper` (Code → Download ZIP на GitHub, розпакуй куди завгодно).
2. Двічі клацни **`Livequid.bat`**. Перший раз він сам створить окреме середовище в папці `.venv` (~1 хв, потрібен Python 3.10–3.13; якщо його нема — запропонує поставити через winget). Далі запускається миттєво, без вікна консолі.
3. Іконка (крапелька) з'явиться в треї — зазвичай у прихованих піктограмах (стрілка ^). Права кнопка: **Пауза**, **Запускати разом з Windows**, **Вийти**. Подвійний клік — пауза.

Нічого не ставиться в систему: усе лежить у цій папці; єдиний слід поза нею — запис автозапуску, і лише якщо ти сам його ввімкнеш у меню.

- `Stop.bat` — зупинити (якщо трей недоступний). Також Ctrl+Alt+Q.
- `Uninstall.bat` — зупинити, прибрати автозапуск і `.venv`; після цього можна видалити папку.
- Якщо не запустилось — дивись `livequid.log` у папці.

Налагодження у вікні: `.venv\Scripts\python main.py --windowed`. Опції: `--particles 300` (більша клякса), `--fps 30`, `--field-scale 0.35` (легше).

## Файли
`Livequid.bat` запуск · `main.py` цикл і вікно · `tray.py` іконка в треї й автозапуск · `winutil.py` вбудування за іконки, монітори, курсор · `sim.py` фізика гелю · `renderer.py` шейдери.
Константи фізики — на початку `Gel.__init__` (`sim.py`), вигляд скла — у `GLASS_FS` (`renderer.py`).

Примітка: код перевірено на Linux (headless OpenGL), на самій Windows із двома моніторами не запускався.
