# Livequid wallpaper (Windows)

Живі шпалери на всі монітори як одне полотно: тонка темно-зелена «матрична» сітка
і велика прозора гелева (liquid glass) клякса в невагомості.

- **Курсор штовхає гель.** Швидкий рух розбризкує клякса на краплі, повільний — акуратно деформує.
- **Повільний курсор збирає краплі** (як магніт); краплі, що торкнулись одна одної чи кляксі, зливаються.
- Краплі летять як у невагомості, відбиваються від країв моніторів (по об'єднанню прямокутників моніторів, тож через стик екранів гель тече вільно).
- Легкий: Python + OpenGL, гель рендериться в напіврозширенні, фізика ~0.5 мс/крок; пауза, коли відкрито повноекранну гру/відео.

## Запуск
1. Python 3.9+ , потім `install.bat` (ставить glfw, moderngl, numpy).
2. `run.bat` — шпалери. Вихід: **Ctrl+Alt+Q** або `stop.bat`.
3. Автозапуск: покласти ярлик на `run.bat` у `shell:startup`.

Налагодження у вікні: `python main.py --windowed`. Опції: `--particles 300` (більша клякса),
`--fps 30`, `--field-scale 0.35` (легше).

## Файли
`main.py` цикл і вікно · `winutil.py` вбудування за іконки, монітори, курсор · `sim.py` фізика гелю · `renderer.py` шейдери.
Константи фізики — на початку `Gel.__init__` (`sim.py`), вигляд скла — у `GLASS_FS` (`renderer.py`).

Примітка: код перевірено на Linux (headless OpenGL), на самій Windows із двома моніторами не запускався.
